# Airplay Android

Android AirPlay 音频接收示例，适用于将 Android 设备作为音乐接收与显示终端。

## 功能

- 接收 AirPlay 发送的音乐并播放；
- 显示歌曲名称、歌手和专辑名称；
- 显示 AirPlay 发送的专辑封面；
- 显示播放进度和音频格式；
- 支持音量变化和播放状态更新；

## 示例

Demo 展示了 AirPlay 音乐接收、PCM 音频播放、歌曲元数据显示和专辑封面显示。

## 技术来源

本项目基于 [juhovh/shairplay](https://github.com/juhovh/shairplay) 进行 Android 适配。
